# BE — apps/api và packages/contracts

Nhãn áp dụng theo [delivery-gates.md](../delivery-gates.md); chỉ chặn khi MUST đúng phạm vi và gate đã kích hoạt.

- **BE-01 MUST [FEATURE:api] — Composition:** `app.ts` tạo app có thể test bằng `inject`, không listen. `server.ts` xử lý khởi động/shutdown; `composition.ts` nối dependency. Đăng ký module/plugin tường minh lúc đầu để Dev lần theo được thứ tự; chưa dùng magic autoload.
- **BE-02 MUST [FEATURE:api,ai] — Schema:** mọi input API (params/query/body) và response JSON có schema; DTO suy ra từ schema TypeBox trong contracts. Validate trước side effect. Runtime phải validate JSON từ CLI/file/network; TypeScript type không thay validation. Fastify validator/serializer và TypeBox/provider phải tương thích phiên bản.
- **BE-03 MUST [FEATURE:api] — API:** prefix `/api/v1`; URL danh từ số nhiều. List trả `{ items, nextCursor }`, giới hạn page size. Create trả 201; nhận job trả 202 cùng run ID/status URL; cancel đang xử lý trả 202; truy vấn thành công trả 200. Không tạo job hoặc review qua GET.
- **BE-04 MUST [FEATURE:api] — Lỗi:** service dùng AppError với code ổn định; handler chung ánh xạ 400 input/schema, 404 không tồn tại, 409 xung đột/trạng thái/version, 413 vượt kích thước, 500 lỗi không dự kiến, 503 runtime chưa sẵn sàng. Response `{ error: { code, message, requestId, details? } }`; details đã lọc. Không trả stack, command, credential hoặc absolute path nội bộ. Lỗi background được lưu trên run; không sửa response Start đã trả 202.
- **BE-05 MUST [FEATURE:api] — Nghiệp vụ:** service không nhận request/reply; repository không quyết định HTTP code hoặc gọi AI. Giao tiếp module qua service/public port. Không vòng lặp import; lỗi nghiệp vụ rõ tên như ACTIVE_RUN_EXISTS, ARTIFACT_VERSION_CONFLICT.
- **BE-06 MUST [LIVE] — Local HTTP:** bind loopback, kiểm tra Host/Origin và bảo vệ API dữ liệu/SSE/export khỏi request trái phép. Chọn một cơ chế local tối thiểu và test được; session-cookie cần chống CSRF, không bắt buộc xây account/login tổ chức. Không wildcard CORS, không coi thiếu Origin là cho qua, không đặt token trên URL/log. Test origin/Host lạ và thiếu credential. Trước LIVE, scaffold fixture có thể chưa có cơ chế này nếu không expose source/CLI thật. Xem [gate LIVE](../delivery-gates.md).
- **BE-07 MUST [FEATURE:api,ai] — Logging:** structured log với requestId/runId khi có; log tại ranh giới chịu trách nhiệm xử lý. Redact token, cookie, prompt, source text và stdout thô. Chỉ expose log đã lọc cho UI; dùng mã lỗi và hành động khắc phục thay nội dung bí mật.
- **BE-08 MUST [LIVE] — Instance/shutdown tối thiểu:** ngăn hai backend dùng cùng data directory bằng lock local hoặc cơ chế tương đương đã test. Shutdown ngừng dispatch, dừng process có deadline, ghi state rồi đóng tài nguyên. Lock cũ không rõ ownership thì báo/chặn và có hướng dẫn xử lý thủ công; không bắt buộc tự sửa mọi stale lock hoặc distributed lock. Không xóa lock/kill PID chỉ vì thấy số PID cũ.

Ví dụ: `POST /api/v1/projects/:projectId/runs` validate body, gọi `jobService.start`, trả 202. Logic claim slot/đọc source không được nhét vào callback route.

- **BE-09 MUST [FEATURE:api] — Nhận diện lỗi:** public error code được khai báo trong contracts; producer mapping có kiểm tra type đầy đủ và chỉ xuất message an toàn. Handler phân loại bằng AppError hoặc lỗi framework được nhận diện; không gom mọi status 4xx từ dependency thành INVALID_INPUT. Unknown error dùng fallback nội bộ, giữ request ID; không dùng message làm discriminator. Xem [mẫu policy và lỗi API](../patterns/api-errors-policy.md).
