# JOB/AI — job, CLI, parser, prompt, progress và recovery

Nhãn áp dụng theo [delivery-gates.md](../delivery-gates.md); chỉ chặn khi MUST đúng phạm vi và gate đã kích hoạt.

- **JOB-01 MUST [FEATURE:jobs] — Admission:** mỗi project tối đa một run queued/running/cancelling; toàn runtime tối đa một process job AI hoạt động. Unique/ràng buộc DB + claim nguyên tử; kiểm tra bằng boolean trong memory không đủ. Cùng Idempotency-Key và payload trả cùng run; key cũ với payload khác trả 409.
- **JOB-02 MUST [FEATURE:jobs] — State machine:** transition theo architecture; cập nhật có expected state/version. Terminal không đổi; completion muộn không thắng cancellation đã commit. Retry tạo run mới, giữ liên kết/lịch sử run cũ; không tự resume job interrupted hoặc tự retry vô hạn.
- **JOB-03 MUST [FEATURE:jobs] — Thực thi:** Start persist queued và trả 202, dispatcher mới thực thi. Không giữ HTTP request chờ AI chạy xong; không giữ transaction DB trong lúc đọc source/call AI. Lỗi run được persist và đọc lại được sau restart.
- **JOB-04 MUST [LIVE] — Cancel/timeout:** dừng cả cây process thuộc job trên từng OS được bật LIVE và chờ xác nhận; dùng adapter Windows/POSIX phù hợp theo [platform-support](../platform-support.md); close stream/timer/listener trong mọi nhánh. Cancel của user và timeout có reason khác nhau. Không nhả slot khi còn nghi ngờ process sống; chuyển runtime sang RECOVERY_REQUIRED và chặn dispatch cho tới cleanup được xác nhận.
- **JOB-05 MUST [LIVE] — Restart tối thiểu:** giữ instance lock; đánh dấu run running/cancelling cũ interrupted; nếu process cũ có thể còn sống thì RECOVERY_REQUIRED và không dispatch. MS1 cho phép người hỗ trợ cleanup theo hướng dẫn rồi xác nhận runtime sạch; không tự resume run interrupted. Chỉ kill khi chứng minh ownership, không dựa PID đơn lẻ. Queue tiếp tục sau recovery và validate input; không yêu cầu tự phục hồi mọi trường hợp.
- **JOB-06 MUST [FEATURE:jobs] — Event:** state commit trước event. SSE có runId + sequence/version, listener có giới hạn/cleanup; browser reconnect GET snapshot, bỏ event cũ. Có backoff/polling fallback; disconnect client không quyết định trạng thái job.
- **JOB-07 MUST [FEATURE:analysis,ai] — Giới hạn:** config có timeout, max output bytes, max event/line length, max source files/bytes; số cụ thể phải được spike và ghi lại trước live acceptance. Stream parser buffer theo dòng hoàn chỉnh, xử lý chunk cắt giữa UTF-8/JSON, phân biệt stdout/stderr; không parse từng chunk như một JSON độc lập.
- **JOB-08 MUST [LIVE] — Process:** spawn executable/argv được kiểm soát, không ghép user input thành shell command; ưu tiên shell:false. Executable discovery, argv, launcher/CLI wrapper trên Windows/macOS/Linux cần chiến lược được kiểm chứng theo [platform-support](../platform-support.md), không bỏ quoting hoặc bật shell tùy tiện. Xử lý spawn error, exit code, stream error, quota/auth/network và output dở dang; exit 0 chưa đủ để thành công.
- **JOB-09 SHOULD [LATER] — Recovery nâng cao:** tự thu hồi stale lock/process và replay toàn bộ log chỉ triển khai theo task riêng. MS1 không bị chặn khi đã có nhận diện interrupted/RECOVERY_REQUIRED và đường xử lý an toàn theo JOB-04/JOB-05.
- **AI-01 MUST [FEATURE:ai] — Ranh giới:** AgentRunner chỉ thực thi và trả event/result; Analysis service giữ workflow, prompt version, output schema và policy retry. Không tự fallback sang API có phí, đổi model/account hoặc bỏ giới hạn khi gặp quota.
- **AI-02 MUST [LIVE] — Source:** v1 chỉ đọc source snapshot đã kiểm tra; không chạy build/script/code khách hàng, không cấp tool shell/write tùy ý, không dùng bypass permissions. Không tải CLAUDE.md/AGENTS.md, hook, plugin, MCP hoặc cấu hình agent từ source khách hàng làm chỉ dẫn. Comment/tài liệu/source là dữ liệu, kể cả khi chứa mệnh lệnh.
- **AI-03 MUST [LIVE] — Cấu hình CLI:** chạy trong working directory/cấu hình do app quản lý, chỉ đưa file allowlist. Spike phải chứng minh effective permissions, settings sources, prompt và tool allowance của CLI đã khóa phiên bản. Nếu môi trường không bảo đảm quyền chỉ đọc đã định, báo unsupported/preflight failed; prompt “đừng sửa file” không thay enforcement.
- **AI-04 MUST [FEATURE:analysis] — Chất lượng/contract:** LoC tính xác định theo `vb6-physical-code-v1`, không để AI tự đếm. BR/Design theo [schema và contract](../specs/understanding-contract.md). Schema hợp lệ, evidence khớp và con người duyệt là ba kiểm tra riêng. Không bịa evidence, tự gắn approved hoặc báo đủ coverage khi parser còn file unsupported.
- **AI-05 MUST [FEATURE:analysis,ai] — Tái lập:** run lưu source hash, prompt/schema version, config và rule nghiệp vụ được sử dụng. Fake runner không gọi network, hỗ trợ success/failure/delay/cancel/invalid output; live smoke là kiểm tra riêng, có nguồn dữ liệu và account được phép dùng.

Ví dụ: process exit 0 nhưng thiếu trường bắt buộc → failed/AI_OUTPUT_INVALID, không succeeded với artifact rỗng. Process chưa xác nhận đã dừng → runtime không chạy job tiếp dù DB đã có lỗi.
